## 3. Caveats

- **Prisma Generator vs Shared Types**:
  - While `crm_cv_speed_profile` table is generated by Prisma in `apps/api`, `@mos-lab/shared` types serve as the transport contract across client, web frontend, and backend API. Database models in `apps/api` should be mapped cleanly to `CvSpeedProfile` DTOs.
- **Service Mode Logic**:
  - `normal_clean` vs `normal_removal` requires querying prior order history (within 2 months). The backend service will populate `serviceMode` based on this logic; the TS interface strictly models the 3 string literal union values.
